Orbit Privacy Policy

Effective date: October 7, 2026 · Applies to Orbit version 2026.10.07 and later

Orbit is a desktop widget that shows your Codex (and, optionally, Claude Code) usage limits and local usage statistics. Orbit is an independent, unofficial app and is not affiliated with or endorsed by OpenAI or Anthropic.

Information Orbit reads on your computer

  • Sign-in information of Codex stored by the Codex app on your computer (%USERPROFILE%\.codex\auth.json): an access token, your account ID and the email address of your account.
  • Sign-in information of Claude Code, only if Claude Code is installed (%USERPROFILE%\.claude\.credentials.json and %USERPROFILE%\.claude.json): an access token, your plan type and email address.
  • Local session logs of Codex and Claude Code (%USERPROFILE%\.codex\sessions, %USERPROFILE%\.claude\projects), from which Orbit counts the number of tokens used per day. Orbit only reads token counts and timestamps; it does not store the content of your conversations.

Information Orbit sends over the network

To display your current usage limits, Orbit sends your access token directly to the service that issued it:

  • Codex: https://chatgpt.com (OpenAI)
  • Claude Code: https://api.anthropic.com (Anthropic) — only when you turn on “Show Claude Code”.

These requests happen when Orbit starts, when you refresh manually, or at the auto-refresh interval you choose (off by default). The same request is made by Codex and Claude Code themselves to show your limits. Orbit does not send your data to the developer of Orbit or to any other party, and contains no analytics, advertising or tracking.

Information Orbit stores

Orbit stores your preferences (language, theme, window position and so on) and a statistics cache (daily token counts) in your user profile on this computer. You can delete the cache at any time in Settings → Cache → Clear. Uninstalling Orbit removes the app; the uninstaller can also remove your preferences and cache.

Children

Orbit is a developer tool and is not directed at children.

Orbit 隐私政策

生效日期：2026 年 10 月 7 日 · 适用于 Orbit 2026.10.07 及之后的版本

Orbit 是一个桌面小组件，用于显示 Codex（以及可选的 Claude Code）的使用额度和本机使用统计。Orbit 是独立的非官方应用， 与 OpenAI、Anthropic 没有任何关联，也未获其认可。

Orbit 在你的电脑上读取的信息

  • Codex 的登录信息（由 Codex 保存在 %USERPROFILE%\.codex\auth.json）：访问令牌、账号 ID 和账号邮箱。
  • Claude Code 的登录信息（仅在安装了 Claude Code 时；%USERPROFILE%\.claude\.credentials.json 与 %USERPROFILE%\.claude.json）：访问令牌、套餐类型和账号邮箱。
  • 本机会话日志（%USERPROFILE%\.codex\sessions、%USERPROFILE%\.claude\projects）： Orbit 只从中统计每天使用的 token 数量和时间，不保存任何对话内容。

Orbit 通过网络发送的信息

为了显示当前额度，Orbit 会把访问令牌直接发送给签发它的服务：Codex 发往 https://chatgpt.com（OpenAI）； Claude Code 发往 https://api.anthropic.com（Anthropic），且仅在你打开"显示 Claude Code"时发送。 这些请求只在启动、手动刷新或你设置的自动刷新间隔（默认关闭）时发生，与 Codex、Claude Code 自己查询额度的请求相同。 Orbit 不会把你的数据发送给 Orbit 开发者或任何第三方，也不包含任何统计分析、广告或跟踪。

Orbit 保存的信息

Orbit 会在本机的用户目录中保存你的偏好设置（语言、主题、窗口位置等）和统计缓存（每天的 token 数量）。 你可以随时在 设置 → 缓存 → 清理 中删除缓存；卸载 Orbit 会移除程序，卸载时也可以选择同时删除偏好设置与缓存。
