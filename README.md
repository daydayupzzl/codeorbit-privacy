## Product name
Code_Orbit

## Short description
Your Codex and Claude Code usage limits, always visible at the top of your screen.

## Description
Code_Orbit is a quiet, Apple-style desktop widget for people who code with AI. It sits at the top of your screen like a
Dynamic Island and shows how much of your Codex usage is left — no need to open a terminal or a settings page.

- Live limits — Codex 5-hour and weekly limits with reset countdowns, at a glance
- Claude Code (optional) — track Claude Code limits too; hidden by default, turn it on anytime
- Usage stats — weekly charts and a monthly activity calendar built from your local session logs
- Fluid design — a compact pill that expands into a card, 5 color palettes
- 7 languages — English, 中文, 日本語, 한국어, Español, Français, Русский
- Private by design — Orbit reads only the sign-in information and logs already on your computer and talks only to the
  services that issued your sign-in. No accounts, no analytics, no ads.
